打撃ローテ自動生成

投手・捕手の連続起用と、打撃（マシン＋打者2人）を同時に計算します。
ローテ本数は「投手のみ」以外（=打撃する人）の人数で自動決定します。
生成 / 再生成を押すたびに、別解があれば違うローテが出ます。

ルール
  • 各列：投手1 / 捕手1 / マシン1 / 打者2（同じ列で同一人物は不可）
  • 投手・捕手は連続起用（P連続 / C連続）
  • 打撃は斜め：マシン(r) → 打者1(r+1) → 打者2(r+2)（周回）
  • 制約：投手・捕手の前後は打撃が入らない（不可能ならその列のみ打撃なしへ緩和）
